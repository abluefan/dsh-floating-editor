# 文件夹树的规则

> 📖 返回 [README](../README.md) · 相关：[API.md](API.md) · [PITFALLS.md](PITFALLS.md) · [MAINTAIN.md](MAINTAIN.md)


### 1 多根（Notepad++「Folder as Workspace」风格）
根列表存在 `roots` 里，可以有**任意多个**、互不相干。三个入口：

1. **右键列表空白处** → 弹一个只有「添加文件夹…」的小菜单 → 点了才拉系统对话框（`pick-dir`）
2. **右键某个目录条目** → 「加为根目录」
3. **打开任意文件时自动加根**：把它**所在目录**加进 roots（已存在则不重复加）

### 2 右键菜单

| 右键对象 | 菜单项（按显示顺序） |
|:--|:--|
| **文件** | 打开 / 在文件管理器打开 / 复制路径 |
| **目录** | 在文件管理器打开 / 命令行打开 / 复制路径 / 加为根目录（已是根则不显示） |
| **根** | 在文件管理器打开 / 命令行打开 / 复制路径 / 移除此根目录 |
| **列表空白处** | 添加文件夹…（**仅此一项**） |

> 目录**故意没有**「进入此文件夹」—— 点条目本身就是展开/收起。

### 3 三道防爆限制

| 限制 | 值 | 位置 |
|:--|:--|:--|
| 单个目录最多列出的条目 | **2000**（Host 截断，返回 `total` / `truncated`） | `index.js` `ENTRY_LIMIT` |
| 一次最多展开的节点数 | **60** | `client.js` |
| 树里最多渲染的可见条目 | **4000**（超出截断并提示） | `client.js` |

### 4 「文件树可写」开关

默认**关**。开启后，树里那些「用户主动加进来的根」也算进可写范围 ——
实现方式是**扩大 workspaceRoot 到那些根**，策略仍是 `workspace-write`，
**不是 `danger-full-access`**，也没有绕过 DSH 沙箱。

> 命名说明：一度想叫「工作区可写」，但会和 DSH 自己的 workspace（= 进程 cwd
> `<DSH 根目录>`）撞名，所以叫「**文件树可写**」。

### 5 装载时校验根列表（2026-09-26 晚加）

`client.js` 挂载后会用 `list` 当探针逐个探每个 root：**只有明确报
「不是目录」的才剔除**；盘符离线、目录暂时不存在等情况**一律保留**，
避免误删用户自己加的根。清掉时会往状态栏写一行提示。

—— 这是为了兜住坑 ⑧ 那种脏数据（旧版本把「文件」存成了根）。
